## 🌟 Overview

A production-ready full-stack travel booking application built for **MANAAR TRAVELS & TOURS LIMITED** (Maktab-Manaar Avenue, Igbe, Ikorodu, Lagos State, Nigeria).

The platform integrates:
- **Flight Booking System**: Compare fares across Saudia, Emirates, Qatar Airways, Turkish Airlines, and British Airways.
- **Hotel Booking Engine**: Discover 5-star Haram view luxury hotels in Makkah & Madinah, Dubai resorts, and global city stays.
- **Hajj Pilgrimage Portal**: 21-Day VIP Royal Hajj & Economy Hajj 2026 packages with pilgrim document verification.
- **Umrah Marketplace**: Pre-configured Ramadan & 5-Star Executive Umrah packages + Custom Umrah Package Request Builder.
- **Visa Application Portal**: Searchable country visa cards (UAE, Saudi Arabia, UK, USA, Schengen Europe, Turkey, Qatar) with live reference tracking.
- **Tour Marketplace**: Guided city experiences, desert safaris, and historical Ziyarat tours.
- **Universal Cart & Secure Checkout**: Bundled items checkout supporting Paystack, Flutterwave, Korapay, and Bank Transfers.
- **Customer Dashboard**: Overview of bookings, visa status stream, documents vault, and printable PDF vouchers.
- **Admin Dashboard & CRM**: Analytics, inventory manager, pilgrim document approval, visa status updater, and staff role switcher (Super Admin, Booking Agent, Visa Officer, Hajj/Umrah Officer, Finance Officer).

---

## 🛠️ Stack & Technologies

- **Framework**: [Next.js](https://nextjs.org/) (React 18 + TypeScript)
- **Styling**: Modular CSS Custom Design System (Tokens for Deep Navy `#0B192C`, Gold `#D4AF37`, Ivory Cream `#FAF9F5`, Glassmorphism, Responsive Grid)
- **Icons**: [Lucide React](https://lucide.dev/)
- **PDF Voucher Engine**: Client printable invoice & travel voucher generator
- **State & Storage**: Universal Cart Context, Multi-Currency Context (NGN, USD, GBP, EUR, SAR, AED), Local Database Service Layer (`dbService.ts`)
